Inventory Optimization API

Welcome to the Multi-AI Agent Inventory Optimization System API.

Available Endpoints:

  • /reports/inventory-status - Generate inventory status reports
  • /reports/forecast - Generate forecast reports
  • /reports/policy-evaluation - Generate policy evaluation reports
  • /reports/supply-chain - Generate supply chain performance reports
  • /reports/dashboard - Generate interactive dashboard

Use the reporting client to interact with this API.
